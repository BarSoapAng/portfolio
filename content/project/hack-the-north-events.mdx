## What I built

This event dashboard turns Hack the North's event data into a browsable schedule with both chronological cards and a visual calendar. Attendees can filter by event type, expand descriptions, inspect speakers and related events, and jump directly between connected sessions.

The interface combines a paper-like background, hand-drawn type, and restrained color coding so a dense schedule stays readable.

## Technical highlights

- React event processing and GraphQL data fetching
- FullCalendar list and time-grid views
- dynamic event-type and private-event filters
- Google Calendar and Outlook export links
- responsive layouts plus keyboard navigation and ARIA labeling
- Motion-powered scroll cues and related-event navigation
