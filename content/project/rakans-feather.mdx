## My first real game &lt;3

In high school I was absolutely obsessed with League of Legends and Arcane, so naturally I turned my computer science project into a little game about them.

You wander through a tile-based world, talk to NPCs, and hunt down the objects they ask for. I drew the characters and environments, built the interactions, added the audio, and somehow got the whole thing into a playable Java build.

Looking back, the code is very much high-school Angela code LOL. But this was one of the first projects that made me fall in love with building things, and I am still so proud of it.

## I basically made everything

- a Java game loop, rendering panel, and keyboard controls
- text-based tile maps with collision detection
- NPC dialogue and collectible-object interactions
- my own sprite sheets, environmental tiles, and sound playback
- a downloadable JAR in the repo if you actually want to play it :)
