## What I built

Rakan's Feather is a 2D treasure-hunt game inspired by League of Legends and Arcane. The player explores a tile-based map, talks to NPCs, and searches for the objects they request.

It began as a high-school computer science project and grew into a complete playable Java build with custom characters, environments, interactions, and audio.

## Technical highlights

- Java game loop, rendering panel, and keyboard input
- text-based tile maps with collision detection
- NPC dialogue and collectible-object interactions
- custom sprite sheets, environmental tiles, and sound playback
- a downloadable JAR included in the repository
