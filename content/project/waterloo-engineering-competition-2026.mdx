## What I built

This single-page site gives Waterloo Engineering Competition attendees one place to find the event schedule, map, sponsors, competition information, and FAQs.

The visual direction turns the event into a bright day at the beach. Illustrated signs, waves, clouds, surfboards, and an interactive camera make the practical event information feel inviting instead of institutional.

## Technical highlights

- responsive React and TypeScript components built with Vite
- reusable styled-components layout and typography primitives
- dedicated desktop and mobile navigation
- section-based navigation for the schedule, map, sponsors, and FAQ
- locally hosted display and body fonts
