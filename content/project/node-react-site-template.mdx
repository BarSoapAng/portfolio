## What I built

This is the starting point I use for small static sites when I want the speed of Vite without rebuilding the same responsive and visual foundations. It combines utility classes with styled-components, then adds the layout shells, typography primitives, breakpoints, and local fonts I reach for most often.

The template stays intentionally small so a new project begins with useful structure instead of inherited product decisions.

## Technical highlights

- React and TypeScript application powered by Vite
- Tailwind CSS v4 alongside styled-components
- reusable page, content, and section wrappers
- typed device breakpoints and media-query helpers
- bundled Satoshi and Castledown font files
- ESLint and production build scripts ready to run
