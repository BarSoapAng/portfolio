## My "I refuse to set this up again" repo

Every small website used to start with the same little ritual: install Vite, wire up Tailwind, add styled-components, hunt down my fonts, and rebuild the exact same responsive wrappers. I got tired of pretending this was productive, so I shoved it all into one template.

It has the visual foundations I reach for every time without deciding what the actual site should look like. Just enough opinion to get moving, not enough to make every project feel like a clone.

## What's already waiting

- React + TypeScript powered by Vite
- Tailwind CSS v4 living peacefully beside styled-components
- reusable page, content, and section wrappers
- typed breakpoints and media-query helpers for the responsive stuff
- Satoshi and Castledown bundled locally
- lint and production build scripts ready from the first commit
