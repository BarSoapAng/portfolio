## What I built

This Discord bot brings LeetCode practice into a community server. It automatically posts each day's challenge with its difficulty and topic tags, while a `/streak` command lets members check their maximum streak without exposing their LeetCode username in the response.

It also packages recurring moderation work into permission-aware slash commands for announcements, rules, and cross-channel messages.

## Technical highlights

- Discord.js slash-command discovery and guild registration
- scheduled daily challenge posts with rich embeds
- LeetCode GraphQL requests for challenge and streak data
- difficulty-based colors and topic metadata
- ephemeral validation errors for private command feedback
- administrator-only controls for announcements and server setup
