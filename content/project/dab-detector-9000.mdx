## What I built

DAB Detector 9000 turns a webcam feed into an intentionally over-the-top pose detector. When the arm geometry matches a dab, the browser adds rainbow color effects, pixel sunglasses, bouncing sprites, and a soundtrack.

After the pose holds for several frames, the app automatically exports a still image so the result can escape the browser.

## Technical highlights

- MediaPipe Pose Landmarker running against live browser video
- pose classification based on shoulder, elbow, wrist, and visibility data
- GPU initialization with a CPU fallback
- canvas-based effects, image compositing, and automatic JPEG export
- a parallel Python implementation using OpenCV, Pygame, and Pillow
