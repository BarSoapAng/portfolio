## Quality of Life

These dotfiles probably singlehandedly saved me hours of dev time. It keeps my most-used terminal workflows consistent across Bash, Zsh, and PowerShell (although I never use POSH LOL). Each shell sources a small shared setup from `~/.dotfiles`, so a new environment can pick up the same navigation, Git, linting, and repository shortcuts without replacing the entire system profile.

The collection also watches each repository's `.nvmrc` and switches Node versions when needed, super useful for switching between projects. This script was actually developed for HTN's insanely messy node versioning haha

## The little things doing the work

- one setup shared across dedicated Bash, Zsh, and PowerShell profiles
- the same aliases for navigation, Git, linting, and dotfile updates everywhere
- automatic `.nvmrc` detection and Node switching without me thinking about it
- checkout and rebase helpers smart enough to find the default branch
- worktree commands for creating and jumping between my many parallel realities
- file-opening behaviour that survives macOS, Linux, and Windows
