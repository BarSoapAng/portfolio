## What I built

These dotfiles keep my most-used terminal workflows consistent across Bash, Zsh, and PowerShell. Each shell sources a small shared setup from `~/.dotfiles`, so a new environment can pick up the same navigation, Git, linting, and repository shortcuts without replacing the entire system profile.

The collection also watches each repository's `.nvmrc` and switches Node versions when needed, cutting out a tiny piece of setup friction every time I move between projects.

## Technical highlights

- dedicated Bash, Zsh, and PowerShell profiles
- matching aliases for navigation, Git, linting, and dotfile updates
- automatic `.nvmrc` detection and Node version switching
- default-branch-aware checkout and rebase helpers
- centralized worktree creation and navigation commands
- cross-platform file-opening behavior for macOS, Linux, and Windows
