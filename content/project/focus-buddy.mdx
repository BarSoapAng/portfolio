## What I built

FocusBuddy watches the active browser tab, evaluates whether its content supports the user's current focus session, and responds without treating every entertainment platform as automatically unproductive.

The extension talks to a FastAPI backend that normalizes URLs, considers page context, and asks Gemini for structured learning and procrastination classifications. Session history is stored through Supabase so the system can reason about browsing patterns over time.

## Technical highlights

- Chrome extension listeners for tab changes and URL checks
- structured Gemini outputs for learning, classification, and procrastination scores
- FastAPI routes for URL checks, session creation, and visualizations
- Supabase-backed authentication and browsing sessions
- tests for URL normalization, classification, debounce behavior, and AI integration
