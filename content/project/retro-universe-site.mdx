This project is the personal website itself. The goal was not sleek minimalism.  
The goal was a loud, memorable page that feels like a saved folder from the early 2000s.

## What I built

- App Router pages for home + long-form content
- reusable retro UI cards and navigation modules
- local MDX content loading for editable writing
- a color token system with vintage paper + candy accents

## Why it matters

I wanted a home on the internet that feels hand-placed and imperfect in a good way.  
The layout keeps personality front-and-center while still staying readable and maintainable.

## Stack notes

- Next.js + React + TypeScript
- Tailwind utilities with custom CSS variables
- MDX frontmatter for content management
