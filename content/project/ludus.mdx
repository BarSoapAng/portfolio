## What I built

Ludus is an AI game-building workspace created as a Bloom take-home project. A user describes a game, a planning agent turns that request into an implementation path, and a coding agent works against an Expo project with tools for reading, editing, creating, deleting, and running files.

The interface keeps the process visible through streamed chat, persistent threads, a browsable code tree, Monaco previews, and follow-up prompt suggestions. Generated projects run in isolated sandboxes and can be opened as live previews.

## Technical highlights

- Next.js and TypeScript interface backed by Convex threads and workflows
- separate planning and game-generation agents with streamed output
- bounded filesystem and command tools for agentic code generation
- isolated sandboxes and per-thread project state
- Monaco Editor and React Complex Tree code exploration
- AI-generated next-step recommendations for iterative prompting
