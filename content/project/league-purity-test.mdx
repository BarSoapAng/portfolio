## What I built

League Purity Test is a 100-question web quiz for comparing the delightfully questionable milestones people collect while playing League of Legends. Each checked experience lowers the player's purity score, which can then be shared through a score-specific URL or posted directly to X.

The quiz reached more than 50,000 users in its first two weeks with zero downtime. At its peak it served over 27,000 requests in one day while keeping average latency below 50 milliseconds.

## Technical highlights

- responsive React and Vite single-page experience
- score calculation from 100 checkbox responses
- shareable results persisted in URL query parameters
- custom Google Analytics events for submissions and shares
- search metadata, a sitemap, and robots configuration
- Cloudflare deployment built for low-latency traffic spikes
